# Calculator

A phone app (installable web app) version of the Calculator from Claude Tools.

- Type whole sums with brackets, powers, roots and n!
- sin, cos, tan and their inverses in degrees or radians (inverse answers also in degrees-minutes-seconds)
- Calculator-style percent: 200 + 15% = 230
- History, memory and Ans
- Works offline once installed

## Install

Open the app's GitHub Pages address on your phone, then:

- **Android (Chrome):** tap **Install app**, or ⋮ → **Add to Home screen**
- **iPhone (Safari):** Share → **Add to Home Screen**

This folder is generated by `build-phone-app.ps1` from the Calculator in the Claude Tools repository. Edit the calculator there, not here.
